The FMUSER FUQ-3702 is a 1U HD IP decoder with dual IP inputs, single IP output, two bi-directional ASI ports, and dual HD/SD-SDI outputs featuring embedded audio. It decodes MPEG-2 and H.264 video streams, supporting audio formats like MPEG1 Layer2, LC-AAC, and HE-AAC. This rack-mountable unit includes web-server remote control for management. Ideal for broadcast headends, cable television systems, and IPTV deployments. It is a 1-U case supporting both IP and ASI input. After decoding process, it outputs 2 channels of HD/SD-SDI videos with dual stereo audios embedded in each port.
